# Demo Web Shop Automation Project

This repository contains an automated testing framework 
designed for the **Tricentis Demo Web Shop** e-commerce platform. 
The goal of this project is to practice test automation, 
implement best practices, and ensure the quality 
of core user journeys on the website.

**Target Website:** 
https://demowebshop.tricentis.com/

## Project Overview
The project focuses on automating functional end-to-end (E2E) scenarios,
ensuring that critical business flows work seamlessly. 

### Key Features to Automate:
**User Authentication:**
Registration, login, and logout verification.
**Shopping Cart & Wishlist:** 
Adding/removing items, verifying cart calculations, and product updates.
**Product Catalog:** 
Global search functionality, category filtering, and sorting.
**Checkout Flow:** 
Simulating the complete step-by-step purchase process.

## Tech Stack & Tools
* **Language:** Python 3.x
* **IDE:** PyCharm
* **Version Control:** GitHub
